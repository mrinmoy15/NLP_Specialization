# Natural Language Processing Specialization (DeepLearning.AI)

This repository contains materials, assignments, and notes for the [Natural Language Processing Specialization](https://www.deeplearning.ai/courses/natural-language-processing-specialization/) by DeepLearning.AI. The specialization consists of four courses, each focusing on a key area of NLP, from foundational models to advanced neural architectures.

## Courses Overview

### [Course 1: NLP with Classification and Vector Spaces](https://github.com/mrinmoy15/NLP_Specialization/tree/development/Course1_NLP_Classification_and_Vector_Spaces)
**Description:**
Learn to perform sentiment analysis of tweets using logistic regression and naïve Bayes. Explore vector space models to discover relationships between words, use PCA to visualize those relationships, and implement a simple English-to-French translation algorithm using pre-computed word embeddings and locality-sensitive hashing for approximate nearest neighbor search.

### [Course 2: NLP with Probabilistic Models](https://github.com/mrinmoy15/NLP_Specialization/tree/development/Course2_NLP_Probabilistic_Model)
**Description:**
Apply dynamic programming, hidden Markov models, and word embeddings to autocorrect misspelled words, autocomplete partial sentences, and identify part-of-speech tags for words. Build foundational probabilistic models for language understanding and generation.

### [Course 3: NLP with Sequence Models](Course3_NLP_sequence_model/)
**Description:**
Use dense and recurrent neural networks, LSTMs, GRUs, and Siamese networks in TensorFlow to perform advanced sentiment analysis, text generation, named entity recognition, and identify duplicate questions. Dive into sequence modeling for complex NLP tasks.

### [Course 4: NLP with Attention Models](Course4_NLP_Attention_model/)
**Description:**
Leverage encoder-decoder, causal, and self-attention mechanisms to perform advanced machine translation of complete sentences, text summarization, and question-answering. Learn about state-of-the-art models like T5, BERT, and more using Hugging Face Transformers.

## About the Specialization

This specialization covers how to design NLP applications that perform question-answering and sentiment analysis, create tools to translate languages, and summarize text. These and other NLP applications are at the forefront of the AI-powered future.

**Skills to gain:**
- Sentiment Analysis
- Transformers & Attention Models
- Machine Translation
- Word2vec & Word Embeddings
- Locality-Sensitive Hashing
- Vector Space Models
- Parts-of-Speech Tagging
- N-gram Language Models
- Autocorrect & Autocomplete
- Named Entity Recognition (NER)
- Neural Machine Translation
- T5 & BERT Models

For more details, visit the [official course page](https://www.deeplearning.ai/courses/natural-language-processing-specialization/).
